# notes — 学习笔记与踩坑记录

> 这里是你的「第二大脑」。学到的知识、踩过的坑，都记在这里。

## 这个文件夹放什么？

| 内容 | 说明 |
|---|---|
| 踩坑记录 | 遇到 bug 怎么解决的，下次不再踩 |
| 知识点总结 | 学完一章，用自己的话写一遍 |
| 面试复习 | 学完的东西，这里就是你的复习资料 |

## 笔记放哪？

**每周的代码文件夹**里放 `notes_weekXX_主题.md`（跟着代码走，方便查）：

```
code/week01/notes_week01_environment.md   ← 第 1 周：环境搭建
code/week02-data-types/notes_week02_type.md  ← 第 2 周：数据类型（以后写）
```

**这个 notes/ 文件夹**放「通用型笔记」：不局限某一周的，比如调试技巧、常见错误汇总。

## 踩坑记录模板（照抄这个格式）

遇到 bug 就复制这段，填上内容：

```markdown
### [日期] 一句话说清问题

- **现象**：程序报什么错 / 结果哪里不对
- **原因**：根本原因是什么
- **解法**：怎么改的
- **收获**：下次怎么避免
```

## 记笔记的 3 条原则

1. **用自己的话写**，不要抄视频/抄书（抄了等于没记）
2. **每周日回顾一次**本周笔记，忘了的补上
3. **踩过的坑一定要记**——这是面试时最值钱的东西

> 例子：第 1 周的坑「中文路径导致编译失败」就值得记进这里，以后换电脑也能避开。
