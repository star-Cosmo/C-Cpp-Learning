# notes — 学习笔记与踩坑记录

> 这里是你的「第二大脑」。学到的知识、踩过的坑，都记在这里。

## 命名规则

**所有笔记统一放这个文件夹**，按周命名：`weekNN-主题.md`

```
notes/week01-环境搭建.md
notes/week02-数据类型与IO.md
notes/week03-scanf.md
```

> 其他长期资料（如面试冲刺计划、项目追问树）也用中文名放这里。

## 踩坑记录模板（照抄这个格式）

遇到 bug 就复制这段，填上内容：

```markdown
### [日期] 一句话说清问题

- **现象**：程序报什么错 / 结果哪里不对
- **原因**：根本原因是什么
- **解法**：怎么改的
- **收获**：下次怎么避免
```

## 记笔记的原则

1. **速查表优先** —— 只留干货，不写成大段解释（笔记太长 = 没记）
2. **用自己的话写**，不抄视频 / 抄书
3. **踩过的坑一定要记** —— 面试最值钱的东西
4. 每周日回顾一次，忘了的补上
