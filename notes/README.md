# notes — 学习笔记与踩坑记录

## 一、错误笔记模板

每次遇到 bug，按这个格式记录（这是你未来最值钱的资产）：

```markdown
### [日期] 错误现象一句话

- **现象**：程序报什么错 / 结果哪里不对
- **原因**：根本原因是什么
- **解法**：怎么改的
- **收获**：下次怎么避免
```

## 二、知识点笔记

按章节整理，例如：

```
notes/
├── 01-数据类型.md
├── 02-运算符.md
├── 03-指针.md
└── ...
```

## 三、建议

- 每学完一章，用自己的话写一遍总结（不要抄书）
- 每周日回顾一次本周笔记
- 面试前，这些笔记就是你最好的复习资料
