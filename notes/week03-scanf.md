# 第 3 周笔记：scanf 与输入

## 一、scanf 用法

- `scanf("%d", &a)` —— 读一个整数
- `scanf("%d %d", &a, &b)` —— 空格/回车隔开
- `scanf("%d,%d", &a, &b)` —— **逗号隔开**（输入必须 `3,5`）
- 返回值 = 成功读到的个数（成功 1 个返回 1，失败返回 0）

## 二、`&` 取地址运算符（重点）

- `a` = 变量的**值**；`&a` = 变量的**地址**（门牌号）
- **printf 不用 `&`**（只读值），**scanf 必须加 `&`**（要往地址里写）
- 原因：C 函数参数是**传值**（拿到的是副本），scanf 要写回你的变量，就必须知道它在哪
- 漏 `&` → 变量的值被当成地址 → 程序崩溃（新手第一大坑）
- **看它的办法**：`printf("%p", &a)`（`%p` = 地址专用格式符）
- `&a` 的类型是 `int *`（指向 int 的指针）—— 第 10 章「指针」的入口

```c
int a = 0;
printf("值 = %d\n", a);      // 0
printf("地址 = %p\n", &a);   // 0x7ffd...
scanf("%d", &a);             // 把输入写到这个地址
```

## 三、格式串里"非 % 字符"要原样匹配

- `"%d,%d"` → 输入 `3,5`（带逗号）
- `"%d %d"` → 输入 `3 5`（空格隔开）
- ⚠️ 坑：格式写 `%d,%d`，却输入 `3 5` → 第二个数读不进来

## 四、`%d` / `%s` / `%c` 的区别

| 格式符 | 读什么 | 关键差别 |
|---|---|---|
| `%d` | 整数 | 自动跳过前面的空格 |
| `%c` | 单个字符 | **不跳空格**（空格/回车也当输入） |
| `%s` | 字符串 | 跳空格，**遇到空格就停** |

> 一句话记：`%c` 来者不拒，`%s` 遇空就停。

## 五、格式说明符速查

| 符 | 含义 |
|---|---|
| `%d` `%i` | 十进制整数 |
| `%f` `%.2f` | 小数（默认 6 位 / 保留 2 位） |
| `%c` / `%s` | 单个字符 / 字符串 |
| `%x` `%X` | 十六进制（小写 / 大写） |
| `%o` | 八进制 |
| `%e` | 科学计数法 |
| `%%` | 百分号本身 |
| `%p` | 地址（指针） |
| `%ld` `%llu` | long / unsigned long long |

## 六、5 种输入方式对比

| 方式 | 特点 | 备注 |
|---|---|---|
| `scanf` | 按格式读 | 遇空格停、不检查溢出 |
| `fgets` | **最安全**（限制长度） | 会读入 `\n`，要手动去掉 ⭐推荐 |
| `getchar` | 读单个字符 | **不用 `&`**，"按任意键"常用 |
| `gets_s` | C11 安全版 | 部分编译器不支持 |
| `getch` | 无需回车、可读方向键 | Windows 专用（`conio.h`） |

## 七、scanf 的 3 个坑（整数）

1. **溢出**：数超过 int 范围（±21 亿），scanf 不报错、静默溢出 → 34 位数字得到 -1
2. **未初始化**：`int a;` 忘了 `= 0`，scanf 失败时 a 是垃圾值
3. **非数字输入**：scanf 失败（返回 0）且不写变量，坏数据留在缓冲区

## 八、读中文：char 存不下，要用宽字符 wchar_t

`char` 只有 1 字节，存不下中文（UTF-8 一个汉字 3 字节）→ 用 **宽字符 `wchar_t`**。

**试错路径**（`scanf-use.c` 三个版本）：

1. `char c` —— 1 字节，读中文乱码 / 变 `?` ❌
2. `wchar_t wc` —— 单个宽字符，能存一个中文 ✅
3. `wchar_t str[100]` —— 宽字符串，能存一串中英文混合 ✅

```c
#include <locale.h>
#include <windows.h>

setlocale(LC_ALL, "");        // 让程序支持宽字符读写（必须）
SetConsoleOutputCP(65001);    // 让控制台按 UTF-8 显示中文（Windows 专有）

wchar_t str[100];
wprintf(L"请输入: ");          // wprintf / wscanf = 宽字符版 printf / scanf
wscanf(L"%99ls", str);        // %lc 单个宽字符 / %ls 宽字符串；99 防溢出
wprintf(L"你输入的是: %ls\n", str);
```

**记法**：`L"..."` 宽字符串字面量 · `wchar_t` 宽字符类型（Windows 2 字节）· `wprintf/wscanf` 宽字符版 · `%lc`/`%ls` 单个/字符串 · `%99ls` 限长防溢出

> 💡 两行设置缺一不可：`setlocale` 管"程序认不认宽字符"，`SetConsoleOutputCP` 管"控制台怎么显示"。
