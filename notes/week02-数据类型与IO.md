# 第 2 周笔记：数据类型 + 输入输出

## 速查

| 函数 | 用法 | 要点 |
|---|---|---|
| printf | `printf("%d", a)` | 输出值，**不加 &** |
| scanf | `scanf("%d", &a)` | 输入，**必须加 &**（取地址） |

- 格式符：`%d` 整数 · `%f` 小数 · `%c` 字符 · `%s` 字符串 · `%u` 无符号 · `%x` 十六进制
- 头文件：`#include <stdio.h>` = 引入函数"说明书"；`<>` 找系统库，`""` 找本项目
- 常用头文件：`stdio.h` 输入输出 · `string.h` 字符串 · `math.h` 数学 · `stdlib.h` 内存

## 转义字符

| `\n` | `\t` | `\\` | `\"` | `\'` | `\0` |
|---|---|---|---|---|---|
| 换行 | Tab | 反斜杠 | 双引号 | 单引号 | 字符串结束 |

## 必记 ASCII

```
'0'=48    'A'=65    'a'=97
'A'+32='a'      '7'-'0'=7（数字字符转数字）
```

## 易错点

- `char` 只有 1 字节，**装不下中文**（UTF-8 汉字 3 字节）
- 可能带小数的值（分数/身高/价格）→ 用 `double`
- `'0'`(字符 48) ≠ `"0"`(字符串) ≠ `0`(整数)
- `%c` 出字符、`%d` 出 ASCII 码 —— **字符的本质是整数**
- 数组没有 `\0` 结尾 → printf 乱码；字符串 `"abc"` 自动带 `\0`

## 踩坑

- **scanf 忘加 &**：编译能过、运行崩溃 / 输入不生效 → scanf 要地址，printf 不要
