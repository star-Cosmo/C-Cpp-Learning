# C-Cpp-Learning

> 从零开始，系统学习 C 语言 → 面向 MCU / 嵌入式开发

**学习者**：零编程基础 ｜ 全职学习（6-8 h/天）｜ 目标方向：MCU / 嵌入式

---

## 一、目标

| 层次 | 目标 | 时间 |
|:---:|---|:---:|
| 短期 | 用 C 独立写出 300-500 行、结构清晰的程序 | 3 个月 |
| 中期 | 看懂芯片手册 / SDK 代码，独立驱动常用外设 | 6-8 个月 |
| 长期 | 独立承担 MCU 固件开发（杰理 / 鸿芯等平台） | 12-18 个月 |

---

## 二、学习路线总览

| 阶段 | 内容 | 周期 | 状态 |
|:---:|---|:---:|:---:|
| 0 | 环境搭建 + 第一个程序 | 第 1 周 | ⬜ |
| 1 | C 语言基础语法（变量 / 运算 / 分支 / 循环） | 第 2-5 周 | ⬜ |
| 2 | C 语言核心（函数 / 数组 / 字符串） | 第 6-8 周 | ⬜ |
| 3 | C 语言进阶（指针 / 结构体 / 内存 / 位运算）⭐ | 第 9-13 周 | ⬜ |
| 4 | MCU 与 STM32 入门 | 第 14-20 周 | ⬜ |
| 5 | 嵌入式实战 + 通信协议 + FreeRTOS | 第 21-26 周 | ⬜ |
| 6 | 平台专项（杰理 / 鸿芯） | 第 27 周起 | ⬜ |

## 四、每日学习节奏

| 时段 | 内容 | 时长 |
|---|---|:---:|
| 上午 | 看视频 / 学新知识 | 2 h |
| 上午 | **立刻动手敲代码验证** | 2 h |
| 下午 | 做练习 / 写小项目 | 2 h |
| 下午 | 调试、查资料、记笔记 | 1 h |
| 晚上 | 复盘 + 更新进度表 | 0.5 h |

> ⚠️ 铁律：**学 1 小时，至少写 1 小时代码。看懂 ≠ 会写。**
