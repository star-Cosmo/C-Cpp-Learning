# projects — 综合项目

> 学完一个模块，就做一个**小项目**把知识串起来。光看视频不动手，等于白学。

## 项目是什么？

就像学游泳：看再多教学视频，不下水永远学不会。项目就是「下水游一圈」——

- 把学过的知识点**组合**起来
- 做一个**完整能用**的小程序
- 遇到问题 → 查资料 → 解决 → 能力就涨了

## 每个项目一个文件夹，里面放：

```
projects/猜数字游戏/
├── README.md   # 项目是干嘛的、怎么玩的、遇到了什么问题
├── main.c      # 主要代码
└── ...
```

## 做项目的 3 个要求

1. **独立完成**——卡住了先自己想，实在不行再问
2. **README 必须写**——做了什么、踩了什么坑、学到了什么
3. **完成后提交到 GitHub**——commit 信息用中文，这是你的作品集
