# 第 2 周：数据类型 + 输入输出

## 本周学到的知识

### 1. 输入输出两个函数
- `printf("格式", 变量)` → **输出**：把数据打印到屏幕上
  - `%d` 整数、`%f` 小数、`%c` 字符、`%s` 字符串
- `scanf("%d", &变量)` → **输入**：从键盘读取数据
  - ⚠️ 变量前面要加 `&`（取地址），`printf` 不用加

```c
int age;
printf("请输入年龄：");
scanf("%d", &age);
printf("你 %d 岁了\n", age);
```

### 2. 标准库（Standard Library）
- C 语言**自带**的一堆现成函数，不用自己写
- 按功能分成很多组，每组对应一个头文件：
  | 头文件 | 里面的函数 | 干什么的 |
  |---|---|---|
  | `stdio.h` | printf、scanf | 输入输出 |
  | `string.h` | strlen、strcpy | 字符串处理 |
  | `math.h` | sqrt、pow | 数学运算 |
  | `stdlib.h` | malloc、free | 内存分配 |

## 重点：头文件到底是什么？

### 用「外卖菜单」来理解
- `#include <stdio.h>` 就像**看菜单**——你点菜（调用 printf）之前，得先知道这家店（标准库）有什么菜（函数）
- 头文件 `.h` 里放的不是函数代码本身，而是**函数说明书（声明）**：这个函数叫什么、要传几个参数、返回什么

### 编译器的工作流程
```
#include <stdio.h>
       ↓ 编译器把 stdio.h 的内容【原样复制】粘贴到这一行
printf("hi");   ← 编译器查说明书：哦，printf 存在，参数是字符串，OK 没问题
```

### 为什么不用头文件会报错？
- 不 `#include`，编译器不知道 `printf` 长什么样 → 报「隐式声明」错误
- 就像不看菜单直接喊「来一份弗拉明戈焗饭」，服务员（编译器）听不懂

### 两个细节
- `#include <stdio.h>` 用尖括号 → 去**系统目录**找（标准库）
- `#include "myfile.h"` 用双引号 → 去**当前项目**找（自己写的）

## 3. 转义字符

> 转义 = 转换意思。有些字符没法直接打出来（比如换行、制表符），就用 `\` + 字母来表示。

### 常用转义字符速查表

| 转义字符 | 含义 | ASCII 值 |
|---|---|---|
| `\n` | 换行（最常用） | 10 |
| `\t` | 水平制表符（Tab 键，对齐用） | 9 |
| `\\` | 反斜杠本身（因为 `\` 被占用表示转义） | 92 |
| `\'` | 单引号（字符里用 `'A'`） | 39 |
| `\"` | 双引号（字符串里用 `"hi"`） | 34 |
| `\0` | 空字符（字符串结束标志） | 0 |
| `\?` | 问号（防止三字母词误判） | 63 |
| `\a` | 响铃（终端会"叮"一声） | 7 |
| `\b` | 退格（光标左移一格） | 8 |
| `\r` | 回车（光标回到行首） | 13 |

### 转义字符示例代码

```c
#include <stdio.h>

int main() {
    system("chcp 65001");  // 设置UTF-8

    printf("第一行\n第二行\n");      // \n 换行
    printf("姓名\t年龄\t城市\n");     // \t 制表符对齐
    printf("张三\t20\t北京\n");
    printf("李四\t25\t上海\n");

    printf("路径：C:\\Users\\test\n");  // \\ 打印一个反斜杠
    printf("他说：\"你好\"\n");         // \" 打印双引符
    printf("字符：\'A\'\n");           // \' 打印单引号

    return 0;
}
```

### 输出结果
```
第一行
第二行
姓名    年龄    城市
张三    20      北京
李四    25      上海
路径：C:\Users\test
他说："你好"
字符：'A'
```

### ⚠️ 重要：字符和字符串里的转义

- 字符用单引号：`char c = '\n';` ✅
- 字符串用双引号：`printf("hello\n");` ✅
- 字符串用单引号：`char c = "a";` ❌（类型不匹配）
- 字符用双引号：`printf('hello');` ❌（C 语言不支持）

## 踩坑记录

### 2026-09-21 scanf 忘记加 & 
- **现象**：程序编译通过但运行崩溃 / 输入不生效
- **原因**：scanf 需要把数据存进变量的地址，`&变量` 就是取地址
- **解法**：`scanf("%d", &age)` 记得加 `&`
- **收获**：printf 输出值、scanf 存地址——这是两个函数最大的区别

## 问答自测（2026-09-22 关键字/字符/转义字符）

### Q1. printf 是关键字吗？
✅ **标准答案：不是**。printf 是标准库写好的**函数名**，关键字是编译器内定的保留词（int、char、return 等），不允许占用。

### Q2. int int = 5; 会怎样？
✅ **标准答案：编译报错**。编译器分词时看到 `int int` 直接判定语法错误，因为 `int` 是保留词。

### Q3. 字符型关键字是？
✅ **标准答案：`char`**。还有两个变体：`signed char`（-128~127）、`unsigned char`（0~255）——嵌入式常用 `unsigned char` 存字节。

### Q4. '0' 和 0 的区别？（⚠️ 我答错过）
✅ **标准答案**：
| 写法 | 类型 | 值 |
|---|---|---|
| `'0'` | **字符**（单引号） | 48 |
| `"0"` | **字符串**（双引号） | '0' + '\0' |
| `0` | **整数** | 0 |
> 单引号=字符，双引号=字符串，别混淆！

### Q5. 'A' + 32 = ?
✅ **标准答案：'a'**。ASCII 设计巧：大写小写二进制只差第 5 位，+32/-32 就是大小写互转。

### Q6. %c 和 %d 打印同一个字符？
✅ **标准答案**：`printf("%c", 'A')` 输出 A（当字符看）；`printf("%d", 'A')` 输出 65（当整数看）。**字符的本质就是整数**。

### Q7. \0 是什么？
✅ **标准答案**：值为 0 的字符（空字符），标记字符串**结尾**。`printf("%s")` 读到 \0 就停。
> 💡 陷阱：`char arr[] = {'a','b','c'};` 没有 \0，printf 会继续读内存直到碰到 0 → 乱码。字符串 `"abc"` 自动带 \0。

### 📌 必须记住的 3 个 ASCII 值
```
'0' = 48   'A' = 65   'a' = 97
```
技巧：`'a' - 'A' = 32`；数字字符转数字：`'7' - '0' = 7`（嵌入式解析串口数据常用）。

### 📌 必须条件反射的 6 个转义字符
```
\n 换行    \t 制表    \\ 反斜杠    \" 双引号    \' 单引号    \0 结束符
```
