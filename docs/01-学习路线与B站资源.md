## 二、章节详解（含应用场景）

> **「应用」= 这个知识点在你未来做 MCU 开发时，具体用在哪。**
> 带着这个目的学，效率会高很多。

### 模块一：C 语言基础（第 1-5 周）

| 章节 | 学习内容 | 嵌入式应用 |
|---|---|---|
| **第 1 章** 环境与第一个程序 | 编译器、源文件、编译链接过程、`printf` | 理解「代码怎么变成固件」 |
| **第 2 章** 数据类型 | `int/char/float`、`sizeof`、取值范围、进制转换 | 嵌入式用 `uint8_t/uint16_t/uint32_t`；每个寄存器都有固定宽度 |
| **第 3 章** 运算符 | 算术、关系、逻辑、**位运算入门** | 位运算直接操作寄存器（后面是命根子） |
| **第 4 章** 分支 | `if/else`、`switch`、三目运算符 | 状态机、按键判断、协议解析 |
| **第 5 章** 循环 | `for/while/do-while`、`break/continue`、嵌套 | MCU 主循环 `while(1)`、周期扫描任务 |

### 模块二：C 语言核心（第 6-8 周）

| 章节 | 学习内容 | 嵌入式应用 |
|---|---|---|
| **第 6 章** 函数 | 定义、参数、返回值、递归、作用域、多文件编程 | 驱动分层：HAL 层 / 驱动层 / 应用层 |
| **第 7 章** 数组 | 一维 / 二维、遍历、排序算法 | 数据缓冲区、查表（字库、正弦表、编码表） |
| **第 8 章** 字符串 | `char[]`、`\0` 结尾、`strlen/strcpy/strcmp` | 串口命令解析、日志打印、AT 指令处理 |
| **第 9 章** 综合练习 | 学生成绩管理系统（增删查改） | 把前面所有知识串起来，检验成果 |

### 模块三：C 语言进阶（第 9-13 周）⭐ 最关键

> 这一阶段决定你**能不能干嵌入式**。指针没吃透，后面全是灾难。

| 章节 | 学习内容 | 嵌入式应用 |
|---|---|---|
| **第 10 章** 指针 | 地址、指针运算、指针与数组、**函数指针**、二级指针 | 寄存器地址映射、DMA 缓冲区、回调函数（SDK 里到处都是） |
| **第 11 章** 结构体 | `struct/union/enum`、`typedef`、位域 | 描述寄存器组、设备对象、协议帧 |
| **第 12 章** 内存管理 | 栈 vs 堆、`malloc/free`、内存泄漏、野指针 | 理解内存布局；嵌入式里慎用 `malloc` |
| **第 13 章** 位运算 | `& \| ^ ~ << >>`、置位 / 清零 / 取反 | **GPIO 操作、寄存器配置——核心中的核心** |
| **第 14 章** 预处理 | `#define`、宏函数、条件编译、头文件 | SDK 的宏配置体系（杰理平台全靠宏开关） |
| **第 15 章** 文件操作 | `fopen/fread/fwrite`、文本 / 二进制 | 配置存储、日志记录 |
| **第 16 章** 综合项目 | 链表、环形缓冲区 | 嵌入式最常用的两种数据结构 |

## 五、学习节奏建议

1. **每天**：看 2h 视频 → 立刻敲 2-3h 代码 → 晚上复盘 0.5h
2. **每个语法点**：至少写 5 个小程序，不写等于没学
3. **每周**：闭卷写一遍本周内容，不看任何资料
4. **建立错误笔记**：每个 bug 记「现象 / 原因 / 解法」（放 `notes/`）
5. **卡住超过 30 分钟**：先跳过，继续往下学，回头再理解

## 六、避坑指南

1. ❌ 不要同时看多个老师的课，选一个跟到底
2. ❌ 不要跳过指针，也别怕指针
3. ❌ 不要用「背语法」的方式学，要理解「为什么这样写」
4. ❌ 不要只看不写——这是零基础失败的头号原因
5. ❌ 不要复制粘贴代码，哪怕照着抄也要一个字符一个字符手打
6. ✅ 平台（杰理 / 鸿芯）是**学完 C 之后**的事，现在别纠结
