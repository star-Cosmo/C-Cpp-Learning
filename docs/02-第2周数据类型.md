## 三、必做练习（代码放 `code/week02-data-types/`）

1. **类型大小查询器**：用 `sizeof` 打印所有类型占的字节数
2. **两数计算器**：输入两个数，输出和差积商（体会 `int` 除法的坑）
3. **进制转换器**：输入十进制，输出二进制/十六进制
4. **温度转换**：摄氏 ↔ 华氏（体会 `float` 精度）
5. **溢出实验**：`int` 不断加 1 加到最大值，观察变成负数
6. **圆面积计算**：`float` 和 `double` 各写一遍，对比精度

## 四、嵌入式应用场景

- **`uint8_t / uint16_t / uint32_t`**：嵌入式代码里几乎不用 `int`，全用这种"无符号定长"类型——对应**寄存器宽度**
- **溢出**：MCU 定时器计数溢出、计数器回绕，不懂溢出就写不对延时和 PWM
- **进制**：寄存器配置全是十六进制，是第 13 章位运算的基础
- **有符号/无符号**：写错判断条件程序就出诡异 bug，嵌入式面试必问

## 五、今日第 1 天入门示例

```c
#include <stdio.h>

int main() {
    int age = 20;           // 变量：可以改变
    const float PI = 3.14;  // 常量：不可改变（const）
    char grade = 'A';       // 字符型

    printf("age = %d\n", age);
    printf("PI = %.2f\n", PI);
    printf("grade = %c\n", grade);

    age = 21;               // 修改变量的值
    printf("新的 age = %d\n", age);
    return 0;
}
```
